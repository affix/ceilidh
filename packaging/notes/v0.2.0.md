## Dance pads that actually dance

Xbox 360 dance pads on Linux were being detected and then ignored completely. Re-initialising the joystick subsystem on every hotplug event made SDL announce the pad again, which triggered another re-initialise, so the pad's id kept changing and no step ever matched a binding. That loop is gone, and the default bindings now include buttons 11 to 14, which is where Linux's `xpad` driver puts a 360 dance pad's arrows.

On a pad, Back now leaves a song and returns to the song list, and Start pauses and resumes. The keyboard keeps Escape, Return and Q.

## Timing and scoring

| Setting | What it does |
| --- | --- |
| Input Lag | Shifts only the judging, 0 to 250 ms, to make up for a TV that shows the arrows late. The global offset moves the arrows and the judging together, so it can't fix display lag. |
| Scoring: Casual | Way Off, Miss and mines score 0 instead of taking points away, so a new player's percentage reflects what they hit rather than flooring at 0.00%. Arcade stays the default. |

## Raspberry Pi

Background video is skipped on a Pi 4, which can't decode it and keep the arrows smooth on a 4K display. Songs use their background image instead, and Options shows `IMAGE ONLY (PI 4)`. The Debian package also now builds its bundled virtualenv against the target's Python ABI.
